# SonarQube Offline Report Plugin v1.2.1

Version 1.2.1 is an enterprise-candidate bug-fix release for controlled pilot use on SonarQube Community Build `26.6.0.123539` / Plugin API `13.7.0.4381`.

## PDF workflow fix

- The print view now invokes the browser print dialog after the report document finishes loading instead of relying on a fixed delay in the parent SonarQube page.
- The print view includes a visible **Print / Save as PDF** button when automatic printing is unavailable or dismissed.
- When the browser blocks the popup, the plugin downloads a print-ready HTML file. Open that file and select **Print / Save as PDF** to finish the export.
- The plugin page provides explicit completion and recovery guidance.

Browser security does not allow a web page to silently choose a local PDF destination. In the browser dialog, select **Save as PDF**, review page size/margins, and choose the destination filename.

## Additional changes

- Expanded installation, verification, rollback, and uninstall procedures for Linux, Docker, Docker Compose, Windows, macOS, and other supported deployment environments.
- Retained the CSP-pinned offline runtime, zero-network report behavior, exact print scope manifest, and existing HTML/XLSX/CSV/DOCX/JSON exporters.

## Validation

- Browser/export tests: 19/19 passed.
- Java page-registration test: 1/1 passed.
- Installed on the target Linux Docker deployment; SonarQube returned `UP`
  with restart count 0, one plugin JAR, and matching build/live-asset hashes.
- Print HTML tests cover the visible retry control, print-only hiding, automatic load trigger, exact scope, counts, completeness, and report ID.

## Release posture

This remains a prerelease, not enterprise GA. It does not claim deterministic direct-PDF generation, PDF/A, PDF/UA, encryption, or digital signing. See [Enterprise readiness](https://github.com/architonixlabs/sonar-offline-report-plugin/blob/v1.2.1/docs/ENTERPRISE-READINESS.md) for the remaining gates.
