# SonarQube Offline Report Plugin v1.3.0

Version 1.3.0 is an enterprise-candidate hardening release for controlled pilot
use on SonarQube Community Build `26.6.0.123539` / Plugin API `13.7.0.4381`.
It incorporates the independently validated API, export-security, testing, and
release-governance improvements recorded in the
[review implementation record](https://github.com/architonixlabs/sonar-offline-report-plugin/blob/v1.3.0/docs/REVIEW-IMPLEMENTATION-2026-08-21.md).

## API and data integrity

- Added a 45-second local request timeout, prompt cancellation, abort-aware
  retry waits, and bounded `Retry-After` support.
- Enforced the SonarQube issue API's 10,000-row search window, including the
  duplicate-page edge case, with explicit partial-result provenance.
- Added best-effort issue/component ordering and repeated snapshot checks.
- Prevented main-branch analysis history from being misrepresented as branch or
  pull-request history when the target API does not provide that scope.

## Export hardening

- Extended formula neutralization to full-width formula initiators.
- Added XML 1.0 scalar sanitization and surrogate-safe XLSX truncation.
- Added ZIP path, entry-count, ZIP32, component-size, and total-package bounds
  for generated XLSX and DOCX files.
- Unified issue lifecycle classification across print and DOCX outputs.

## Build and release governance

- Added the SHA-256-verified Maven Wrapper using Maven 3.9.16 and enforced the
  supported Maven/JDK build environment.
- Added a CycloneDX 1.6 JSON SBOM and checksum as release assets.
- Pinned GitHub Actions to immutable revisions and added JAR content, generated
  bundle, license/notice, and SBOM checks.
- Replaced fixed delays in the live-browser helper with bounded state polling.

## Validation

- Browser/export tests: 31/31 passed.
- Java page-registration test: 1/1 passed.
- Generated bundle freshness, Maven Enforcer, plugin packaging, required JAR
  entries, CycloneDX validation, JavaScript syntax, diff checks, and actionlint
  1.7.12 passed before tagging.
- The tag workflow independently rebuilds and verifies the published assets.

## Release posture

This remains a prerelease, not enterprise GA. Transport-level network abort,
target authorization/isolation, HTTPS, live throttling, browser/accessibility,
desktop Office/OpenXML, large-data performance, rollback, signing/provenance,
and organizational SBOM/license approval remain external evidence gates. See
[Enterprise readiness](https://github.com/architonixlabs/sonar-offline-report-plugin/blob/v1.3.0/docs/ENTERPRISE-READINESS.md).
