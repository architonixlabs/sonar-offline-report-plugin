# SonarQube Offline Report Plugin v1.2.0

Version 1.2.0 is an enterprise-candidate release for controlled pilot use on SonarQube Community Build `26.6.0.123539` / Plugin API `13.7.0.4381`.

## Highlights

- Guided project-report workflow with Executive, Standard, Detailed, and Issue Register presets.
- Resize- and zoom-aware plugin scrollbar with bottom clearance for expanded controls.
- Professional, self-contained offline HTML report with actionable KPIs, filtering, issue details, provenance, and print styling.
- Human-readable, styled XLSX and CSV exports.
- Fixed-profile, macro-free DOCX export with a bounded issue appendix.
- Browser **Print / Save as PDF** flow and normalized JSON snapshot export.
- Immutable Report Model v2 with report IDs, dataset health, scope tracking, paging reconciliation, deduplication, and analysis-change detection.
- Restrictive offline CSP, formula-injection protection, fixed public API allowlist, and no server token/database/report storage.

## Installation

1. Download the JAR and matching `.sha256` file from this release.
2. Verify the checksum.
3. Stop SonarQube and back up the previous plugin JAR.
4. Copy this JAR into the persistent `extensions/plugins` directory, ensuring that only one `offlinereport` JAR is present.
5. Start SonarQube and verify `/api/system/status`, the installed plugin version, and a project report page.
6. Use `Ctrl+F5` once after upgrading to bypass SonarQube's static-asset cache.

## Release posture

This is a prerelease, not enterprise GA. Open gates include the negative permission matrix, production HTTPS, Firefox and desktop Office interoperability, accessibility/load testing, fault injection, rollback acceptance, signing/provenance, and approved SBOM evidence. See [Enterprise readiness](https://github.com/architonixlabs/sonar-offline-report-plugin/blob/v1.2.0/docs/ENTERPRISE-READINESS.md) for the complete gate list.

Browser **Print / Save as PDF** is not a deterministic direct-PDF generator and does not claim PDF/A, PDF/UA, encryption, or digital signing.
